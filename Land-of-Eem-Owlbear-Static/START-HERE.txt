LAND OF EEM CHARACTER SHEET FOR OWLBEAR RODEO

This folder is the ready-to-host static extension.

1. Upload ALL files in this folder to an HTTPS static web host.
   Examples: GitHub Pages, Cloudflare Pages, Netlify, Vercel.

2. Find the public URL to manifest.json. It will look like:
   https://your-site.example/manifest.json

3. In Owlbear Rodeo, open your Profile > Extensions > Add Extension.

4. Paste the manifest.json URL and add the extension.

5. Enable the extension in your room.

6. Put the player token on Owlbear's CHARACTER layer.

7. Open the Land of Eem extension, import the .eem.json saved by the
   existing character builder, select the token, and click Save to token.

The character sheet is then stored with the token in Owlbear scene metadata.
Other users in the room will receive scene updates normally through Owlbear.

NOTE ABOUT ONEDRIVE
A normal OneDrive share link is file sharing, not an HTTPS static web host,
so it is not the right install URL for an Owlbear extension.
