OFFLINE BUILDER VERSION: 24

LAND OF EEM CHARACTER BUILDER
Offline Edition — User Guide

GETTING STARTED

1. Download Land-of-Eem-Offline.zip.
2. Extract/unzip the entire ZIP. Do not open the builder from inside the ZIP.
3. Open the Land-of-Eem-Offline folder.
4. Double-click index.html. If prompted, choose Microsoft Edge or Google Chrome.

The offline builder does not need an internet connection, an account, or an
installation. Keep START-HERE.txt and the licenses folder with your copy.

If you received the ZIP through OneDrive, download and extract it first.
OneDrive's file preview will not run the builder.

CREATING A CHARACTER

Follow the seven steps in the sidebar. Use Back and Continue, or click a step
name to return to it.

1. Class: Choose a class, its starting perk options, and any required details.
   Open Class perks reference for explanations and the available choices.
2. Attributes & skills: Assign attributes, choose the skill adjustments, and
   review the resulting skill values in each attribute's card.
3. Folk: Choose your Folk, size, skill bonus and penalty, perks, and any
   required quirk. Choose additional culture options if applicable.
4. Homeland & gear: Choose your homeland and proficiencies, select or roll
   starting equipment, and add any extra equipment approved by your GM.
   Use the Worn checkboxes to identify worn or equipped items. Equipment
   effects are listed beneath the relevant items.
5. Your story: Enter your name, pronouns, backstory, ideal, flaw, allies,
   rivals, personal quest, party relationships, and notes. Class-based
   example dropdowns fill the text fields; you can edit the text afterward.
6. Advancement
   Set an existing character’s level from 1 to 10, or spend XP with Advance.
   Enter unspent XP (not lifetime XP). Choose one earlier ability mastered
   at each level gained. Both abilities at the current level are available.
   Use Core rules or the optional slower XP progression for future purchases.
   At level 5, add a second ideal and flaw. Buy skill ranks one at a time
   (maximum +3) and each stat boost once. At level 10, additional earlier
   abilities cost 40 XP each. Undo purchase controls refund XP.
   Setting the level directly does not charge XP; lowering it refunds any
   recorded level purchases above the new level and level-10 extra abilities.
   Fill in class-specific choices, such as Loyal Pet, Well-Rounded, or the
   permanent Courage roll for a mastered Martial Prowess.

7. Sheet & Roll20: Review the character and any choices still to finish.
   Racial traits, class perks, and class abilities appear in separate groups.

The builder supports levels 1 through 10. Develop party relationships and
personal quests with your group during Session Zero as needed.

SAVING: TWO DIFFERENT METHODS

AUTOMATIC BROWSER DRAFT

The builder automatically keeps your current draft in the browser's local
storage when available. This is browser data, not a separate character file.
It will not appear in Downloads, beside index.html, or in OneDrive.

The automatic draft:
- Belongs to that browser and browser profile on that device.
- Does not automatically transfer to another browser or device.
- Can be lost when browser/site data is cleared.
- May be unavailable or temporary in private/incognito browsing.
- May not follow you if you move or rename the offline HTML file.
- Is separate between the online builder and the offline edition.

Automatic saving is a convenience. Use Save file for a lasting backup.

SAVE FILE — YOUR PORTABLE CHARACTER BACKUP

1. Click Save file at the top of the builder.
2. Your browser downloads an .eem.json character file.
   For example: Kiri-Fuddle.eem.json.
3. Look in your browser's Downloads folder, or the location you selected.
   Your browser may ask where to save, depending on its settings.
4. Move or copy the file into a character folder or OneDrive if you want a
   backup you can find later.

Save file exports your current choices, including an unfinished character.
It does not automatically save beside index.html or directly into OneDrive.
Saving again may create another download with a number added to its name.
Keep the newest file; do not assume the previous file was overwritten.

Suggested organization:
- Keep the offline builder in its own folder.
- Keep .eem.json character backups in a separate Characters folder.
- Save after significant changes and before starting a new character.
- Use dated backup names when you want to retain older versions.

LOADING A SAVED CHARACTER

1. Open the builder.
2. Save the current draft first if you want to keep it.
3. Click Load file.
4. Select the character's .eem.json file.
5. Review the loaded character in Sheet & Roll20.

Loading replaces the current draft. To switch between multiple characters,
keep a separate .eem.json file for each character and load the one you want.
Use Load file rather than opening the JSON file directly in the browser.
Saved character files work between the online and offline editions of this
builder. You can also send a character file to your GM or another player.

BACKUPS AND ONEDRIVE

You can store .eem.json files and PDFs in OneDrive like other documents.
OneDrive can sync those files, but it does not sync the browser's automatic
draft. Each friend has their own browser draft and character files.

When sharing a character, send the .eem.json file if the recipient needs to
edit it in the builder. Send a PDF if they only need to read or print it.

PREVIEW, PDF DOWNLOAD, AND PRINTING

1. Click Preview sheet in the sidebar, or Print sheet at the top.
2. Wait for the sheet to finish preparing. PDF preparation can take a moment.
3. Scroll through the preview to review all pages.
4. Choose Print to open the browser's print dialog.
5. Choose Download PDF to save a PDF copy.
   Supported browsers may show a Save dialog; others use Downloads.
6. If the browser blocks the download, choose Open PDF and save or print
   from the PDF viewer.
7. Use Close preview, or press Escape, to return to the builder.

The sheet uses the supplied landscape character-sheet template. Longer
entries continue onto additional pages. Check the page count before printing.

A PDF is a snapshot for reading and printing. It does not replace the
.eem.json file, which preserves your editable builder choices.

TRANSFERRING TO ROLL20

The Roll20 transfer is manual and works without a Roll20 Pro membership.

1. Ask your GM to select the Land of Eem community character sheet in the
   game's settings and give you access to a character.
2. Open Sheet & Roll20 in the builder.
3. Find the Transfer to Roll20 section.
4. Copy values into the matching Roll20 sheet fields.
5. Add racial traits, class perks, and class abilities as separate entries
   in the sheet's repeating abilities/skills area.
   The entry name appears as its label in the builder; its Copy button
   copies only the description. Enter the name separately in Roll20.
6. Copy the separate note groups into Other Notes as needed.

The .eem.json file is for this builder's Load file button. It is not an
automatic Roll20 import file. Pasting the character summary into Bio & Info
creates readable text but does not fill the playable sheet's fields.

If a Copy button is blocked by your browser, select the displayed text and
copy it manually with Ctrl+C (Windows) or Command+C (Mac).

SHARING THE OFFLINE BUILDER

Send Land-of-Eem-Offline.zip to your friends through OneDrive, email, or
another file-sharing service. Each person downloads and extracts their own
copy, then opens index.html locally. They do not need your account.

The HTML file contains the character data, sheet artwork, fonts, and PDF
libraries. The packaged version does not update itself. Share a newer package
when you want friends to receive changes, and save character backups before
replacing or moving their existing copy.

QUICK TROUBLESHOOTING

- Builder does not open: Extract the ZIP first, then open index.html in a
  browser rather than using a cloud-storage preview.
- Draft is missing: Use Load file to reopen your latest .eem.json backup.
- Cannot find a download: Check your browser's Downloads list and folder.
- PDF is still preparing: Wait for the download button to become available.
- PDF download is blocked: Use Open PDF and the viewer's Save/Download button.
- Browser autosave is unavailable: Use Save file regularly.

LEVEL-10 UPDATE — OCTOBER 6, 2026
Older level-one saves still load. Their level defaults to 1 and XP to 0.
New saves retain level, unspent XP, mastery choices, skill purchases, boosts,
second ideal/flaw and class-specific advancement choices. Load updated saves
with this version of the builder; older versions do not understand advancement.

its own traits. Class-granted items can also appear under Class perks.


OWLBEAR RODEO EXPORT
On Sheet & Roll20, choose Export Owlbear JSON. Select a save slot in Blaze
Sanecki’s Land of Eem extension and use its Import button to open that file.
Import replaces the chosen slot. Current Courage starts at maximum.
Apply conditional equipment effects and fixed Dread bonuses manually.
Keep a normal .eem.json save to continue building and advancing here.
